An Aadhaar number is a 12-digit random number whose final digit is a Verhoeff
checksum, so a malformed number can be rejected offline before any lookup. Aadhaar
authentication (OTP, demographic, or biometric) may be performed only by a
UIDAI-licensed AUA/KUA, routed through an ASA. The number must be masked in
disclosures — only the last four digits may be shown — and must never be stored or
transmitted except as required for a specific, consented authentication.
