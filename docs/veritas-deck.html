One request, four agents, one audited decision

Knowledge base

Verified memory — every fact is hashed and cited

Only files whose SHA-256 matches the manifest are retrievable. Tampered or unlisted files are quarantined — an answer can only be grounded in content provably unchanged.

9 integrity-verified sources · tamper a file → it is quarantined and the chain check reports the break.

Orchestration

Faithful to OpenAI Swarm — agents that hand off

Implemented from github.com/openai/swarm: agents own functions; a function that returns an Agent is a handoff; shared context_variables thread the run.
